## Ejemplos de jueces

Los pares pequeños de entrada y salida en `tests/judges/cases.json` proceden de las páginas públicas de [AtCoder Practice A](https://atcoder.jp/contests/abs/tasks/practice_1?lang=en), [AtCoder Library Practice A](https://atcoder.jp/contests/practice2/tasks/practice2_a?lang=en) y [AtCoder Library Practice B](https://atcoder.jp/contests/practice2/tasks/practice2_b?lang=en). Se conservan exclusivamente como casos de verificación, con la procedencia indicada en el archivo. La licencia del código de este repositorio no sustituye los términos de AtCoder para esos materiales.

## Referencias de implementación

Se consultaron [CodeLibrary](https://github.com/indy256/codelibrary), [AtCoderLibraryForJava](https://github.com/NASU41/AtCoderLibraryForJava) y [KACTL](https://github.com/kth-competitive-programming/kactl) para cobertura, organización y prácticas de pruebas. Las implementaciones Java actuales se escribieron para este repositorio; no se incorporaron archivos fuente de esas colecciones.
